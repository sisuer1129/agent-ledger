# NAS 更新说明

本次修复统计与明细/导出筛选一致性、手机筛选提示与重置、保存后保持统计月份、升级和重启时保护已有分类/标签/规则/账户设置。历史交易和标签关联不做重写。旧人员默认名称在记账选择器中兼容显示。

先将更新包及同名 .sha256 文件上传到 /volume1/docker/finance-api/release-v2，校验成功后解压，进入包目录执行 sudo bash scripts/deploy.sh。

部署会先停止 finance-api，再备份数据库（含存在的 WAL/SHM）、构建目录和容器代码，随后重新构建并启动。期间账本暂时不可用；请等待 Deployment healthy。备份路径会在输出中显示。

如部署失败，先查看 docker logs --tail 100 finance-api。应用启动可能已执行初始化，不能仅凭健康检查失败判断数据库未改变。不要反复运行或直接恢复未知备份。

确需恢复时，在包目录运行 sudo bash scripts/rollback.sh <本次输出的完整备份目录>。回滚会恢复备份时的数据；执行前会把当前数据库及其日志保留到 backups/pre-rollback-*。旧版本脚本生成的历史备份可能缺少 WAL，本脚本无法补回其缺失内容。

验收：选择历史月份，点标签统计查看明细，金额和笔数应一致；手机显示月份、标签、统计范围并可“查看全部”；桌面再次筛选仍保留统计范围；历史月份保存后不跳回本月。

验证范围：自动化回归、本地桌面和手机视图交互、部署脚本隔离测试。NAS/Docker 实机部署需在上传后执行，本地验证不代表 NAS 已更新。
